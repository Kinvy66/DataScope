# 快速开始

> 阶段：Phase 1–4、7、8A、8B、9、10 · 状态：已完成

DataScope 是桌面端多通道时序数据软件。第一阶段不接真实采集卡，用本地文件或数据发生器完成「工程 → 数据 → 波形 → 分析」闭环。

## 环境

- Windows 10/11
- Node.js（能运行 `npm`）

## 安装与启动

在项目目录执行：

```bash
npm install
npm run dev
```

启动后应看到深色工程界面：顶栏、左侧导航、中间工作区、底栏状态。

## 第一次走通

1. **新建工程**（顶栏或工作台，或 `Ctrl+N`）  
   选择一个空目录，填写工程名。磁盘上会生成：

   ```text
   工程名/
   ├── project.json
   ├── data/
   ├── exports/
   ├── analysis/
   └── logs/
   ```

2. **准备数据**，任选其一：
   - **导入**：顶栏「导入数据」，选择 `samples/normal.csv` 或 `samples/perg-ioba-0001.csv`（PERG，日期时间戳）
   - **实时采集模拟**：导航「实时监视」，连接 → 准备 → 开始；停止后可写入工程

3. **看波形**：打开「数据浏览」，下方 Canvas 应出现通道波形。

4. **打 Marker**：在波形上放 Cursor A，点「从 Cursor A 添加 Marker」，或打开「Marker 管理」填写采样点。

5. **做分析**：「信号分析」看统计量，「频谱分析」对生成的正弦跑 FFT，峰值频率应接近设定频率。

6. **看任务**：导入 / 生成 / 分析 / 导出时打开「任务管理」，应出现进度；可暂停、继续、取消或失败后重试。底栏也会显示运行中的任务。

7. **导出数据**：打开「数据导出」，选 CSV / TXT / JSON，文件出现在工程 `exports/` 下，可再导入核对。

8. **保存工程**（`Ctrl+S`），关闭后再用「打开」或最近工程列表打开，数据和 Marker 应还在。

## 示例文件

| 文件 | 用途 |
| --- | --- |
| `samples/normal.csv` | 三通道正常 CSV |
| `samples/normal.json` | JSON 示例 |
| `samples/unicode.csv` | 中文表头 |
| `samples/perg-ioba-0001.csv` | PERG 双通道（RE/LE），日期时间戳；摘自本地 `dataset/` 研究数据 |

仓库根目录的 `dataset/`（若存在）是体积较大的原始测试包（PERG CSV、UCI EEG），默认不进入 Git。PERG 的 `csv/*.csv` 可直接导入；EEG 不是当前 CSV/JSON 格式，请先转换成带表头的 CSV/JSON。
