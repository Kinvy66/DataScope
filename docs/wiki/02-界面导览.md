# 界面导览

> 阶段：Phase 1 · 状态：已完成（后续业务页按各自阶段标注）

## 窗口结构

```text
┌────────────────────────────────────────────┐
│ 图标 · DataScope · 工程按钮 · 导入 · 主题   │  顶栏
├──────────┬─────────────────────────────────┤
│ 导航     │  当前页面（工作区）               │
│          │                                 │
├──────────┴─────────────────────────────────┤
│ 就绪 | 工程名 | 通道数 | 采样点数 | DAQ 状态 | 任务 | 版本     │  状态栏
└────────────────────────────────────────────┘
```

应用图标为青/蓝双通道波形方标，出现在窗口图标和顶栏左侧。侧栏导航、顶栏和主要操作按钮带有线框图标。页面入口只在左侧导航；顶栏只保留工程操作、导入和主题切换，窗口变窄时保持单行。工作台「数据集」等区域内按钮仍会换行，文字不会挤出按钮。

## 主题

应用设置可切换中文 / English、深色 / 浅色、日志级别、自动保存，以及新建工程和发生器 / 导出用的默认采样率、通道数、格式。顶栏也可切主题。`Ctrl+I` 导入数据，`Ctrl+N` / `O` / `S` / `Shift+S` / `W` 对应新建、打开、保存、另存、关闭工程。
