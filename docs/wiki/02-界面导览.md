# 界面导览

> 阶段：Phase 1 · 状态：已完成（后续业务页按各自阶段标注）

## 窗口结构

```text
┌────────────────────────────────────────────┐
│ 图标 · DataScope · 工程按钮 · 导入 · 主题   │  顶栏
├──────────┬─────────────────────────────────┤
│ 导航     │  当前页面（工作区）               │
│          │                                 │
├──────────┴─────────────────────────────────┤
│ 就绪 | 工程名 | 通道数 | 采样点数 | DAQ 状态 | 版本     │  状态栏
└────────────────────────────────────────────┘
```

应用图标为青/蓝双通道波形方标，出现在窗口图标和顶栏左侧。

## 主题

应用设置或顶栏可切换深色 / 浅色。`Ctrl+I` 导入数据，`Ctrl+N` / `O` / `S` / `Shift+S` / `W` 对应新建、打开、保存、另存、关闭工程。
