# 波形查看

> 阶段：Phase 4、7 · 状态：已完成

在「数据浏览」选中数据集后，下方是多通道 Canvas 波形。软件不会为每个采样点创建 DOM，而是：

```text
Dataset → 当前窗口 → Min-Max 降采样 → Canvas
```

因此 32 通道 × 100 万点也可以缩放、平移。

## 操作

| 操作 | 方式 |
| --- | --- |
| 放大 / 缩小 | 工具栏按钮或滚轮 |
| 平移 | Shift + 拖动 |
| 显示全部 | Fit All 或按 `F` |
| 自动纵轴 | Auto Scale |
| 通道显隐 | 点击通道色块 |
| 通道顺序 | 通道列表上的 ↑ ↓ |
| 同时显示条数 | 通道显示 1/4/8/16/32/64/128 |

## 光标

- 点击放置 Cursor A / B（或按 `A` / `B` 选择下一个要放的光标）
- 右侧读出 Time A/B、Δt，以及各通道 A/B 值与差值
- 「清除 Cursor」去掉两条线

光标处的数值来自当前降采样窗口的近似，不是逐点原始表；精确统计请用「信号分析」。

横轴显示从记录起点起的相对时间。若导入的是日期时间戳，起始墙钟时间仍写在数据集信息里。

## Marker

- 彩色虚线画在波形上，右侧列表可点击跳转
- 「从 Cursor A 添加 Marker」在当前 Cursor A（若没有则用窗口中点）写入一个事件 Marker
- 完整编辑在「Marker 管理」页
