# 信号与频谱分析

## 时域信号分析

> 阶段：Phase 5 · 状态：已完成

打开「信号分析」：

1. 勾选通道
2. 设置起始 / 结束采样点，或点「全范围」
3. 运行分析

得到 Min、Max、Mean、Median、RMS、StdDev、Peak-Peak。结果会写到工程 `analysis/` 下的 JSON，便于留档和测试对照。

数字滤波（高通 / 低通 / 带通 / 陷波 / 去直流作为独立滤波）**尚未实现**。

## 频谱分析

> 阶段：Phase 6 · 状态：已完成

打开「频谱分析」：

1. 勾选通道与区间
2. 选择 FFT 点数（256–16384，必须是 2 的幂）和窗函数
3. 运行 FFT

页面给出：

- 频率轴
- 幅度谱或功率谱（可切换）
- 峰值频率（图上黄线）

用数据发生器生成「采样率 1024 Hz、频率 64 Hz、时长 1 s」的正弦，FFT 点数 1024、矩形窗时，峰值频率应为 **64 Hz**。这是软件测试时很好用的对照实验。
