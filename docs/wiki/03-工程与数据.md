# 工程与数据

## 工程管理

> 阶段：Phase 2 · 状态：已完成

- 新建、打开、保存、另存为、关闭
- 有未保存修改时关闭会询问
- 最近工程列表可一键打开，可清除
- 工程设置可改名称、描述、默认采样率

工程必须先打开，才能导入或生成数据。

## 导入文件

> 阶段：Phase 3 · 状态：已完成

支持 CSV / TXT / JSON。CSV / TXT 需要表头：

```text
timestamp,ch1,ch2,ch3
0.000,1.2,2.3,3.4
0.001,1.3,2.2,3.5
```

JSON 可以是行主序 `[timestamp, ch1, ...]` 或通道主序 `samples[通道][采样点]`。

软件会拒绝：空文件、缺表头、列数不一致、非数字、NaN、Infinity、时间戳回退。中文路径可用。

导入文件会复制到工程 `data/` 目录。

## 数据发生器

> 阶段：Phase 8A · 状态：已完成

在已打开工程中打开「数据发生器」：

1. 选波形（正弦 / 方波 / 三角 / 直流 / 噪声 / 多频）
2. 填通道数、采样率、时长、频率、幅度、偏置、噪声
3. 点「生成并加入工程」

频率必须低于采样率的一半。单通道最多 100 万点，最多 32 通道。生成文件为 JSON，重新打开工程后仍可加载。

多通道使用相同波形、相位错开，方便在波形页区分。

> 阶段：Phase 3 · 状态：已完成
