# 工程与数据

## 工程管理

> 阶段：Phase 2 · 状态：已完成

- 新建、打开、保存、另存为、关闭
- 有未保存修改时关闭会询问
- 最近工程列表可一键打开，可清除
- 工程设置可改名称、描述、默认采样率

工程必须先打开，才能导入或生成数据。

## 导入文件

> 阶段：Phase 3 · 状态：已完成

支持 CSV / TXT / JSON。CSV / TXT 需要表头：

```text
timestamp,ch1,ch2,ch3
0.000,1.2,2.3,3.4
0.001,1.3,2.2,3.5
```

第一列也可以是日期时间，例如 PERG：

```text
TIME_1,RE_1,LE_1
2016-09-15 09:40:21.0000,0,0
2016-09-15 09:40:21.0006,-0.1,0.1
```

JSON 可以是行主序 `[timestamp, ch1, ...]` 或通道主序 `samples[通道][采样点]`。

软件会拒绝：空文件、缺表头、列数不一致、非数字、NaN、Infinity、时间戳回退。中文路径可用。

导入文件会复制到工程 `data/` 目录。

本地目录 `dataset/` 里是完整研究数据（PERG IOBA、UCI EEG 压缩包），默认 gitignore。要在软件里试，请导入 `samples/perg-ioba-0001.csv`，或从 `dataset/.../csv/` 选一条 PERG CSV。EEG 原始文件不是本软件的 CSV/JSON，不能直接打开。

## 数据发生器

> 阶段：Phase 8A · 状态：已完成

在已打开工程中打开「数据发生器」：

1. 选波形（正弦 / 方波 / 三角 / 直流 / 噪声 / 多频）
2. 填通道数、采样率、时长、频率、幅度、偏置、噪声
3. 点「生成并加入工程」

频率必须低于采样率的一半。单通道最多 100 万点，最多 32 通道。生成文件为 JSON，重新打开工程后仍可加载。

多通道使用相同波形、相位错开，方便在波形页区分。

## 实时监视 / Virtual DAQ

> 阶段：Phase 8B · 状态：已完成

打开「实时监视」：

1. 填写通道数、采样率、缓冲点数和波形（默认 10 Hz 正弦）
2. **连接 → 准备 → 开始**
3. 右侧 Canvas 滚动显示环形缓冲里的最新数据
4. 可暂停 / 继续 / 停止；采集中不能断开
5. 停止后若已打开工程，可将缓冲 **写入工程**，之后到数据浏览里当普通数据集看

状态机非法操作会被拒绝。数据包带 CRC；当前是进程内回环，丢包计数在正常采集时应为 0。不接真实网口或采集卡。

## Marker

> 阶段：Phase 7 · 状态：已完成

在「Marker 管理」或数据浏览 / 波形工具栏：

- 添加、修改、删除（名称、类型、采样点、相对时间、可选通道、颜色、描述）
- 非法采样点会被拒绝
- 写入当前工程的 `project.json`，保存后再打开仍在
- 「跳转到波形」会把视窗对准该采样点
